# Fire Calendar: pitch deck

Presentation for NASA Space Apps Challenge 2026, challenge "MODIS and VIIRS Hot Spots".

Open `index.html` in a browser (Chrome recommended, online once so the fonts load).
Arrow keys or space to navigate, `F` for full screen, `N` for speaker notes and timer, `E` to edit text.

`speech.md` holds the speaker script (about 2.5 minutes).

Project: https://github.com/daringzofficial-cloud/fire-calendar
